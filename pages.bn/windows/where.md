# where

> অনুসন্ধান প্যাটার্নের সাথে মিলে যাওয়া ফাইলগুলোর অবস্থান দেখান।
> ডিফল্টভাবে বর্তমান ওয়ার্কিং ডিরেক্টরি এবং `%PATH%` এনভায়রনমেন্ট ভেরিয়েবলে থাকা পাথগুলোতে অনুসন্ধান করে।
> PowerShell-এ এই কমান্ডটি `Where-Object`-এর একটি উপনাম (alias)। এই ডকুমেন্টেশনটি Command Prompt (`cmd`)–এর `where` কমান্ডের উপর ভিত্তি করে তৈরি।
> আরও তথ্য পাবেন: <https://learn.microsoft.com/windows-server/administration/windows-commands/where>।

- সমতুল্য PowerShell কমান্ডের ডকুমেন্টেশন দেখুন:

`tldr where-object`

- ফাইল প্যাটার্নের অবস্থান প্রদর্শন করুন:

`where {{ফাইল_প্যাটার্ন}}`

- ফাইল প্যাটার্নের অবস্থান প্রদর্শন করুন যাতে ফাইলের আকার এবং তারিখও থাকে:

`where /T {{ফাইল_প্যাটার্ন}}`

- নির্দিষ্ট পাথে ফাইল প্যাটার্ন রিকার্সিভভাবে অনুসন্ধান করুন:

`where /R {{ডিরেক্টরি\এর\পাথ}} {{ফাইল_প্যাটার্ন}}`

- কোনো আউটপুট না দেখিয়ে ফাইল প্যাটার্নের অবস্থানের জন্য এরর কোড রিটার্ন করুন:

`where /Q {{ফাইল_প্যাটার্ন}}`
